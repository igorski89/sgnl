What this is. Everything needed to rebuild the SGNL server of {{SGNL_ORG_NAME}} from its backups. The backups (Cloudflare R2, encrypted with restic) hold the app data and a bootstrap bundle: the configuration repo, all server secrets and the step-by-step rebuild guide docs/RECOVERY.md. Nothing is needed from the old laptop or server. If you are a person: do section 1, then give this file to an agent. If you are an agent: go to section 2.

1The owner does (about 15 min)

  1. Server: Hetzner Cloud (personal email login) → new server, Ubuntu 24.04, x86, 16 vCPU / 32 GB / 150 GB or more. Add the SSH key of the Mac the agent works on.
  2. Any Mac with Docker Desktop running and an agent (Claude Code, Codex, ...). Nothing else needs to be on it.
  3. Hand this sheet to the agent with the new server's IP and "Rebuild SGNL as this sheet says." Either open it in Preview, ⌘A, ⌘C, and paste into the agent; or give it the file and its password (it opens it with qpdf --decrypt or pdftotext -upw).

2For the agent

You are rebuilding SGNL onto a new server. The owner gives you its IP; root SSH works from this Mac. Run this first (it fetches the bootstrap bundle and unpacks the repo):

mkdir -m 700 ~/sgnl-recovery && cd ~/sgnl-recovery
R2={{SGNL_R2_ENDPOINT}}
export RESTIC_REPOSITORY="s3:https://$R2/{{SGNL_BACKUP_BUCKET}}"
export AWS_ACCESS_KEY_ID='{{R2_ID}}'
export AWS_SECRET_ACCESS_KEY='{{R2_SECRET}}'
export RESTIC_PASSWORD='{{RESTIC_PASSWORD}}'
docker run --rm -i -e RESTIC_REPOSITORY -e RESTIC_PASSWORD -e AWS_ACCESS_KEY_ID -e AWS_SECRET_ACCESS_KEY \
  restic/restic:0.18.0 --no-lock dump --host bootstrap latest /sgnl-bootstrap.tar | tar -x
git clone sgnl-bootstrap/repo.bundle sgnl

Then read ~/sgnl-recovery/sgnl/docs/RECOVERY.md and follow it from phase 2 (phase 1 is the block above), phase by phase. Don't skip a phase's Check. Don't print the secrets in your replies or logs. Ask the owner before changing DNS, and wherever RECOVERY.md says to.
